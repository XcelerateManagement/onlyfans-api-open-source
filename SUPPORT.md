# Support

## Installation and operation

Start with [SELF-HOSTING.md](SELF-HOSTING.md), especially its troubleshooting,
backup and upgrade sections. For community installation help, use the
[Telegram community](https://t.me/+SCLucm_6IEcwOGYx).

When reporting a reproducible project bug, use the repository's issue forms. Remove
all creator names, fan identifiers, account IDs, message bodies, API keys, cookies,
passwords, proxy credentials and session data before posting logs or screenshots.

## Managed hosting

If you do not want to operate Docker, upgrades, backups and monitoring yourself, see
[The Only API hosted plans](https://theonlyapi.com/pricing) or use the
[company contact form](https://theonlyapi.com/contact).

## Security

Do not report vulnerabilities in an issue, Telegram, or the public contact form.
Follow [SECURITY.md](SECURITY.md) and use GitHub's private vulnerability reporting
form.

## Contribution policy

Issues and feature proposals are public. Pull requests are restricted to project
collaborators. See [CONTRIBUTING.md](CONTRIBUTING.md) for the review, privacy and DCO
requirements.
